# CNPJ Enricher

Esta skill complementa o `CNPJ Lookup`, trazendo informações adicionais da empresa via a Minha Receita API ou Brasil API.

## Quando utilizar
Utilize esta skill quando você precisar descobrir quem são os tomadores de decisão de uma empresa. O Quadro de Sócios e Administradores (QSA) permite identificar os diretores, presidentes e sócios-administradores de um CNPJ.

## Como utilizar
O input para esta tool é o número do CNPJ (formatado ou não).

## Exemplo de Resposta
A resposta incluirá a lista de sócios (nome e cargo) e outras informações detalhadas como CNAEs secundários e capital social.
